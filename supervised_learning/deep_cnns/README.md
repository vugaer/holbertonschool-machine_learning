Deep Convolutional Neural Networks
Description

This project focuses on implementing core concepts of deep convolutional neural networks, specifically architectures like Inception and ResNet using TensorFlow (Keras).

The goal is to understand how modern CNN architectures work and how they solve problems like the vanishing gradient problem.

Learning Objectives

At the end of this project, you should be able to explain:

What is a skip connection
What is a bottleneck layer
What is the Inception Network
What are ResNet, ResNeXt, and DenseNet
How to replicate a network architecture from a research paper


Concepts
Convolutional Neural Networks (CNN)
1x1 Convolution
Residual Connections
Batch Normalization
ReLU Activation
Deep architectures (ResNet, Inception)
