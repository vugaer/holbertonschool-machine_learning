# Dimensionality Reduction

## Description

This project focuses on implementing core dimensionality reduction algorithms from scratch using NumPy.

The tasks cover:

- Principal Component Analysis (PCA)
- t-Distributed Stochastic Neighbor Embedding (t-SNE)
- Entropy calculations
- Affinity computations
- Gradient calculations
- Cost optimization

The goal of the project is to understand how high-dimensional data can be transformed into lower-dimensional representations while preserving important structural information.

---

# Learning Objectives

At the end of this project, you should be able to explain:

- What dimensionality reduction is
- Why dimensionality reduction is important
- The curse of dimensionality
- How PCA works mathematically
- How t-SNE works internally
- Difference between linear and nonlinear dimensionality reduction
- Similarity distributions in high-dimensional and low-dimensional spaces
- KL divergence optimization
- Gradient descent in t-SNE
